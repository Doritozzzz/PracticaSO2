Primera entrega de la practica de Sistemas Operativos II, en esta implementamos una primera parte de un sistema de gestión
de ficheros (que simula un ext2). En esta construimos desde las operaciones más básicas un sistema capaz de escribir y leer
bloques de informacion divididos según una serie de bloques lógicos y inodos.
